# Design checklist

Print this next to a new `template.yaml`. Official sequence from [use cases](https://docs.x.ai/grok-bot/use-cases).

- [ ] One job a stranger could score
- [ ] Distinct tools/sources
- [ ] Distinct working style
- [ ] Distinct approval boundary
- [ ] Description holds standing rules; messages hold this-task
- [ ] Deliverable is reviewable (facts / inferences / done / waiting / questions)
- [ ] First task runs on an empty chat or asks for the one missing input
- [ ] No-data and stale-data policy
- [ ] Week one is L1
- [ ] Skill six fields ready after a success
- [ ] Routine only after two good runs + test run + missing-source policy
- [ ] Group handoff has one owner per stage
- [ ] Share-safe (no secrets, no internal URLs)
- [ ] `grokbot score` ≥ 80
