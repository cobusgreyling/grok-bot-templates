## Template

Copy this into `docs/field-cases/<id>.md` after you actually ran it.

```md
# Eng team on <repo> — week of YYYY-MM-DD

- Team: Eng (bug-reproduction, issue-drafter, pr-reviewer)
- Repo: public URL or "private, described"
- Plugins: GitHub
- Autonomy: L1 the whole week

## What happened
- Day 1: …
- Day 3: …
- Day 7: …

## Artifacts (redacted)
Link or paste the review pack / unsent issue / repro notes. Fake names only.

## Never-list hits
What the Bots refused, and whether that was right.

## Still typed by hand
The steps a human still had to do.

## Would we enable a routine?
Yes / not yet — and why.
```
