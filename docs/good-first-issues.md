# Good first issues

Small, reviewable contributions. Read [CONTRIBUTING.md](../CONTRIBUTING.md) and [SPEC.md](../SPEC.md) first.

## Fastest paths

| Issue type | What to do | Ready when |
|------------|------------|------------|
| Convert a prompt | Follow [convert/](../convert/) for a Claude / ChatGPT / Cursor bot you already run | `grokbot score <id>` ≥ 80, L1, `share_safe: true` |
| Score a public share link | Pick a bot on grokbot.dev, write what the never-list is missing | Comment or a convert PR, not a paste of their prompt |
| Localization | Japanese or Chinese `PROFILE.md` is generated — add `soul` / `tagline` notes in `docs/` for translators | One template, one language, no invented job |
| Pages polish | Screenshot of a first-run artifact for `examples/` | Fake names only (`Acme North`, `PR #184`) |

## Not first issues

- New marketplace UI
- Scraping private share links
- L3 routines that send, pay, or merge
- Persona packs without a job

Open the issue with the template, or skip straight to a PR from `grokbot new`.
