# Official alignment

This catalog is **not affiliated with xAI**. It is written against the public Grok Bot docs as of 2026-08-29.

| Doc | What we took |
|-----|----------------|
| [Get started](https://docs.x.ai/grok-bot/get-started) | Eligible plan, desktop app, first task shape (outcome, sources, constraints, deliverable, review point) |
| [Bots](https://docs.x.ai/grok-bot/bots) | One job; description vs message; duplicate for scope; share link copies config not computer; 50 Bots+groups cap |
| [Use cases](https://docs.x.ai/grok-bot/use-cases) | Official job shapes (Outbound, Talent Scout, Paid Media, Expense Manager, Product Performance, Bug Reproduction, Account Health, Chief of Staff) and the seven-step "turn an example into a durable Bot" |
| [Skills and routines](https://docs.x.ai/grok-bot/skills-routines-and-automations) | Six-field skill; routine confirms; test run is real work; no broad listeners; 50 routines / 20 run records |
| [Computer and apps](https://docs.x.ai/grok-bot/computer-and-apps) | One shared computer; connectors as Plugins; `/workspace`; takeover for 2FA |
| [Approvals](https://docs.x.ai/grok-bot/approvals-security-and-privacy) | Standing boundaries; Auto Review; local computer policy; share is not a security boundary |
| [Chat](https://docs.x.ai/grok-bot/chat-and-collaboration) | Groups 2–6; `@` mentions; visible handoffs; one owner per stage |
| [Files](https://docs.x.ai/grok-bot/files-and-results) | Reviewable artifacts; facts / inferences / completed / waiting / questions |
| [Settings](https://docs.x.ai/grok-bot/settings-and-notifications) | Timezone for routines; Plugins marketplace vs Yours |

If a template contradicts these, the docs win. Open an issue.
