# Plugins (connectors)

Official: **Settings → Plugins**. Marketplace vs Yours. Installed connectors are **account-wide**, not per-Bot. Prefer a connector over clicking a website. Type `@` to attach a connector; `/` for a skill.

This catalog names plugins as they appear in profiles (`GitHub`, `Gmail`, `Slack`, `X`, `LinkedIn`, `Notion`, `Google Calendar`, `Google Drive`, `Google Docs`). The live marketplace set changes. If a name is missing in your app, use the browser on the shared computer and say so in the first-run notes.

Because connectors are shared:

- Do not treat "only this Bot has Gmail" as a control
- Sign out of a service when the whole roster should lose it
- Revoke at the source provider, not only in Grok Bot

Team installer lists the **union** of plugins, once.
