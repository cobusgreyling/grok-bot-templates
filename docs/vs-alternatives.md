# vs alternatives

Grok Bot templates exploded the week share-links shipped. Most directories optimize for **discovery**. This repo optimizes for **contracts you can score**.

| | grok-bot-templates | awesome-grokbot | grokbot.dev | bots.new |
|--|--|--|--|--|
| Unit of value | Operating contract + score | Copy-paste PROFILE.md | Public share URL | Named role card |
| Machine schema | Yes (`template.yaml`) | Partial frontmatter | API envelope | Unspecified |
| Autonomy levels | L0–L3 | Implicit never-send | Varies per author | Varies |
| CLI | `npx github:cobusgreyling/grok-bot-templates` | — | — | — |
| CI | Schema, secrets, score, drift | — | — | — |
| Teams as DAG | `teams/*.yaml` + kickoff | START.md teams | Some agent-team tags | Packs |
| Skills / routines | First-class six-field / test_first | Mentioned | `includes: schedule` flags | — |
| Official-docs alignment | Cited in SPEC and patterns | Practical, informal | Marketplace | Marketplace |
| Installer | START.md | START.md | Agent contract | Add to Grok |
| License | MIT | CC0 | Site terms | Site terms |

Use this repo when you want **week-one L1**, a never-list that survives a new thread, and a PR that fails if someone ships a persona without a job.

Use grokbot.dev when you want to **try a live share link** someone posted today.

Use awesome-grokbot when you want another prompt to read. Do not paste both catalogs into one Bot.

None of these are xAI official. Official use cases live at [docs.x.ai/grok-bot/use-cases](https://docs.x.ai/grok-bot/use-cases).
