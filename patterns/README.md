# Design patterns

Twelve rules distilled from the official Grok Bot docs. Each is a `pattern.yaml` CI validates.

| Pattern | Rule |
|---------|------|
| [one-job-per-bot](./one-job-per-bot/) | Outcome, not a department |
| [description-vs-message](./description-vs-message/) | Standing rules in the description |
| [draft-then-routine](./draft-then-routine/) | Skill before schedule |
| [standing-approval-boundary](./standing-approval-boundary/) | Never-list is not optional |
| [shared-computer-is-not-isolation](./shared-computer-is-not-isolation/) | One computer per account |
| [group-for-visible-handoffs](./group-for-visible-handoffs/) | 2–6 Bots, one owner per stage |
| [skill-six-fields](./skill-six-fields/) | When, inputs, sequence, validate, return, approval |
| [no-data-policy](./no-data-policy/) | Missing ≠ invented |
| [share-sanitizer-before-link](./share-sanitizer-before-link/) | Public links copy config |
| [smallest-useful-roster](./smallest-useful-roster/) | Four is a team, fifty is a ceiling |
| [evidence-bearing-results](./evidence-bearing-results/) | Facts / inferences / waiting |
| [duplicate-for-scope-not-security](./duplicate-for-scope-not-security/) | One Account Health per region, not per secret |

See [SPEC.md](../SPEC.md) and [docs/official-alignment.md](../docs/official-alignment.md).
