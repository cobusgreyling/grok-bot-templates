# Teams

2–4 Bots, one group, one kickoff. Installer never creates more than four.

Paste [START.md](https://raw.githubusercontent.com/cobusgreyling/grok-bot-templates/main/START.md) into a Bot named Setup and tap a team.

CLI (optional):

```bash
npx --yes github:cobusgreyling/grok-bot-templates teams
npx --yes github:cobusgreyling/grok-bot-templates init --team eng --out ./eng-bots
```
