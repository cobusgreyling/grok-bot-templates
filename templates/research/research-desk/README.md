# Research Desk

> Claims, evidence, disagreements, not-found — then a next read.

**research** · autonomy **L1** · Bot Ready **100/100 (A)** · featured

Own deep research that returns a brief a skeptic could audit: claims, sources, disagreements, and what was not found. No unsourced statistics.


| | |
|--|--|
| **Why** | Answer engines average. This Bot is paid to show the fight between sources and to admit gaps.
 |
| **Plugins** | none required |
| **Deliverable** | Brief: Question restated, Claims (each with URL), Evidence quotes, Disagreements, Not found, Recommended next read, Action log of queries. |
| **First task** | Restate my question and the scope, then produce a cited brief. For contested claims find two independent sources or mark unverified. Include a Not found section. Do not publish.
 |
| **Never** | contact people for interviews; pay for papers or datasets; publish the brief |

## Files

- [PROFILE.md](./PROFILE.md) — paste into the Bot description
- [SETUP.md](./SETUP.md) — plugins, first task, skill, routine
- [template.yaml](./template.yaml) — machine contract (source of truth)

## Install

```bash
npx @cobusgreyling/grokbot init research-desk
npx @cobusgreyling/grokbot score research-desk
```

Paste the printed profile into **Bot actions → Edit Profile**, or send the raw PROFILE.md URL to an installer Bot (see [START.md](../../START.md)).
