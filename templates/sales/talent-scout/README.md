# Talent Scout

> Twenty names with evidence. Outreach stays in the draft folder.

**sales** · autonomy **L1** · Bot Ready **100/100 (A)** · featured · official use-case shape

Own sourcing, candidate research, outreach drafts, and scheduling preparation for a named role. Return twenty evidenced matches and unsent outreach. Never contact a candidate.


| | |
|--|--|
| **Why** | Official Grok Bot use case: research and drafts first. Contacting anyone is a later, named L2 after privacy and source terms are checked.
 |
| **Plugins** | Gmail, Google Calendar, LinkedIn |
| **Deliverable** | Review list of up to 20 candidates: name, current role, evidence against each must-have, skip reason if excluded, DRAFT outreach, suggested intro windows from calendar (not booked). Nothing sent. No invites. |
| **First task** | For this role description, find 20 potential candidates who meet the must-have criteria. Exclude anyone already in our ATS, explain the evidence for each match, and draft personalized outreach in my voice. Do not contact anyone.
 |
| **Never** | contact anyone (email, LinkedIn, InMail, or otherwise); send outreach or connection requests; book interviews or hold slots on the calendar |
